Before you start

1Place the desk

Allow the camera, move the tablet slowly over a table or the floor, then tap the glowing circle.

2Wake it up

Tap a computer part. Nothing happens! The parts need programs, so wake them up.

3Find the pairs

For each mission, tap the hardware and the software that work together.

What you will find

✋ Hardware

If I can touch it, it is hardware!

  • 🖱️ Mouse
  • ⌨️ Keyboard
  • 🖥️ Monitor
  • 🔊 Speaker
  • 📱 Tablet
  • 🤖 Robot

✨ Software

If I cannot touch it, it is software!

  • 🎨 Drawing app
  • 📝 Writing app
  • 🎬 Video app
  • 🎵 Music app
  • 📷 Camera app
  • 🧩 Program app

Bonus: the robot from last session drives across the desk. IF its sensor sees something, THEN it stops. Walk up to it to test the condition.

Camera note: this activity uses the camera only inside the browser to understand the surface around the tablet. It does not record or upload video. If markerless AR is unavailable, the activity offers interactive 3D and marker-based backups with the same missions.
